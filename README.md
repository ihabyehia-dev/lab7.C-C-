# C Lab - Arrays and Strings

This lab works with array and string functions and a separate program to test them.

## Exercises
- Sum integer array values
- Reverse an array
- Count occurrences of a character in a string
- Count letters regardless of case

## Files
`lab5.c` and `lab5main.c` are the main exercise. The practice program uses `lab5practice.c`, `lab5practice.h` and `lab5practicemain.c`.

## Compile and run
```bash
gcc -Wall -Wextra lab5.c lab5main.c -o lab5
./lab5
```

Compile the practice files separately. Check empty arrays, single-element arrays, and case-sensitive vs. case-insensitive character counts.
